# Social Links Profile - Frontend Mentor

Esta é a minha solução para o desafio [Social links profile do Frontend Mentor](https://frontendmentor.io). Este projeto é um cartão de perfil social moderno e responsivo.

## 🚀 O Projeto

O objetivo deste desafio foi construir um cartão de perfil com links sociais e deixá-lo o mais próximo possível do design original.

### ✨ Demonstração
- **Link do projeto online:** [https://ipsant.github.io/projetos/social-links-profile-main/]

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica.
- **CSS3:** Estilização, variáveis globais (`:root`) e efeitos de hover.
- **Flexbox:** Utilizado para centralização total do conteúdo na tela e organização dos elementos.
- **Fontes Locais:** Implementação de fontes personalizadas via @import e diretórios locais para melhor performance e controle de recursos.

## 🧠 O que eu aprendi

Durante o desenvolvimento deste projeto, foquei em:
1. **Centralização perfeita:** Aprendi a usar `display: flex` no `body` com `min-height: 100vh` para garantir que o card fique no centro em qualquer tela.
2. **Variáveis CSS:** Facilitei a manutenção do código criando uma paleta de cores centralizada no `:root`.
3. **Responsividade:** Uso de `max-width` para garantir que o card se ajuste a celulares pequenos sem quebrar.
4. **Pseudo-classes:** Aplicação de `:hover` e `:active` (com `transform: scale`) para melhorar a experiência de clique do usuário.
